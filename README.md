# cruntime: the sysroots

This branch holds the files, one directory per operating system, release and architecture (`linux/debian13/aarch64`, `windows/x86_64`, `openbsd/v80/x86_64` ...).  What they are, where each came from and under what license is in the README of the `main` branch, which is also the site: https://moebiusv.github.io/cruntime/.  The branch is kept apart so that the site is a few kilobytes and not a gigabyte.
